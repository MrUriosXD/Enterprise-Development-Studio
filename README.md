# Enterprise Development Studio

> Entorno de desarrollo web para crear, editar, organizar y previsualizar proyectos desde una interfaz centralizada.

## 📌 Descripción

**Enterprise Development Studio** es un entorno de desarrollo web orientado a facilitar la creación y edición de proyectos directamente desde el navegador.

El proyecto combina un editor de código con una vista previa en tiempo real, permitiendo trabajar con contenido web y comprobar rápidamente cómo se adapta a diferentes dispositivos y tamaños de pantalla.

Actualmente se encuentra en una fase inicial y está planteado como una base sobre la que seguir incorporando herramientas y funcionalidades de desarrollo.

## ✨ Características

- 💻 Editor de código integrado.
- 👁️ Vista previa del contenido en tiempo real.
- 📱 Modos de previsualización para escritorio, tablet y móvil.
- 🔄 Orientación vertical y horizontal para dispositivos compatibles.
- 🖥️ Modo de vista previa a pantalla completa.
- 🔍 Herramientas de búsqueda dentro del editor.
- 🌙 Tema oscuro y ☀️ tema claro.
- 📐 Ajuste del tamaño de los paneles mediante divisor redimensionable.
- 📏 Indicador visual de dimensiones durante la previsualización.
- 📊 Barra de estado para mostrar información del entorno de edición.
- 🎨 Interfaz inspirada en herramientas modernas de desarrollo.
- 📦 Aplicación completamente basada en tecnologías web.

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript
- Web APIs del navegador

No requiere un backend ni un proceso de compilación para ejecutar la versión actual.

## 🚀 Uso

La versión actual puede ejecutarse directamente desde el navegador.

1. Clona el repositorio.
2. Abre `index.html` en un navegador web moderno.
3. Utiliza el editor para introducir o modificar el contenido.
4. Comprueba el resultado mediante el panel de previsualización.
5. Cambia entre los diferentes modos de dispositivo según sea necesario.

También puede publicarse como una aplicación web estática mediante servicios compatibles con sitios estáticos.
